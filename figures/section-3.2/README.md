# 3.2 图件管理

管理主题：ARG 丰度、组成及风险分类相关图件。该主题仅用于组织归档，不预设结果、显著性或机制结论；正式章节标题与面板内容待核验稿件确认。

当前仅有目录占位，无图件、实验数据或分析结果。预留管理 ID 为 `S32-F001`，不是正式论文图号。

| 子目录 | 用途 |
| --- | --- |
| `svg/` | SVG 矢量导出 |
| `ppt/` | PPTX／PPT 交付文件 |
| `tiff/` | TIFF 投稿导出 |
| `source/` | 原生编辑工程、素材及制作记录 |
| `code/` | 绘图、排版、导出代码 |

遵循[目录说明](../../docs/directory-structure.md)和[命名规范](../../docs/naming-conventions.md)。新增文件须更新 [Figure index](../../FIGURE_INDEX.csv)，并可复制[版本历史模板](../../templates/version-history.md)到本目录。不存在的文件路径留空；科学内容保留未核验状态，直至完成来源核对。
